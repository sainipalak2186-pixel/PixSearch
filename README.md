# PixSearch🔍

PixSearch is a simple image search web application built using **HTML, CSS, JavaScript, and the Unsplash API**.

## Features

- 🔎 Search for images
- 🖼️ Display 15 images for each search
- 🎨 Simple and clean user interface
- ⚡ Fetches images using the Unsplash API
- 📱 Responsive image grid

## Technologies Used

- HTML
- CSS
- JavaScript
- Unsplash API

## How to Run

1. Clone or download the project.
2. Open `script.js`.
3. Add your Unsplash **Access Key**.
4. Open `index.html` in your browser.
5. Search for any image you want.
